# Learn { #learn }

Here are the introductory sections and the tutorials to learn **Logust**.

You could consider this a **book**, a **course**, the **official** and recommended way to learn Logust. 😎

* [Tutorial - User Guide](../tutorial/index.md): everything you need for day-to-day logging, step by step. Each section builds on the previous one.
* [Advanced User Guide](../advanced/index.md): extra features for when you need more control, like custom levels, `opt()`, background writes, performance tuning and canonical events.
* [How To - Recipes](../how-to/index.md): self-contained recipes for specific problems, like intercepting the standard `logging` module, FastAPI integration, or migrating from loguru.
